# Cross-Set Analysis v1.5

## Scope
This analysis integrates three structured-observation sets:
- Set 1: funding/problem-framing ecosystem (50 observations)
- Set 2: AI/AI-bio evaluations (42 observations)
- Set 3: relational trajectories (42 observations)

These are not representative samples. Percentages and correlations are descriptive of the coded corpus and are hypothesis-generating only.

## Added analytical codes
- Claim–demonstration distance (0–4)
- Configuration level (model-only -> agent/tools -> human-AI -> physical)
- Boundary sensitivity (1–4)
- Construct/ecological/predictive validity scales
- Physical validation indicator
- Feedback chain: available -> interpretable -> update capacity -> update observed

## Descriptive results
- 30/42 Set 2 evaluations (71.4%) are coded high/very-high boundary sensitivity.
- 37/42 (88.1%) have predictive validity coded unknown or low.
- Mean claim–demonstration distance: 1.77/4.
- Mean claim distance by configuration: model-only 2.07; agent/tools 1.81; human-AI 1.67; physical 1.44.
- Mean predictive-validity score: model-only 0.00; physical 0.78 on the exploratory 0–4 scale.
- Configuration level correlates positively with predictive-validity score (Pearson r = 0.33) and negatively with claim-distance score (r = -0.49). These are exploratory associations in a current sample.
- Feedback is available in all 42 coded trajectories, but an update is clearly observed in 21/41 codable trajectories (51.2%). Mean feedback-to-update gap is 0.34 on the 0–1 coding scale.

## Cross-set hypotheses
1. System boundary is often outcome-determining.
2. Predictive validity is a weaker link than local construct validity.
3. Claim–evidence distance may shrink as evaluation moves closer to real workflows and physical execution.
4. Feedback is not equivalent to learning; interpretability and update capacity matter.
5. “Human in the loop” is too coarse to be a useful safety variable.
6. Composition can amplify, buffer, or block capability rather than monotonically increase risk.
7. Funding problem frames are upstream inputs to what becomes measurable.
8. Negative and null results may be disproportionately informative about hidden constraints and relational bottlenecks.

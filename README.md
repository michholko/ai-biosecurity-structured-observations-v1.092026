# Structured Observation Analysis of AI-biosecurity Papers in Four Categories 092026

## Purpose

This repository is a shareable snapshot of the structured-observation
research program examining how AI-bio security knowledge changes as the
analytical system boundary expands. The work is exploratory and
hypothesis-generating. The corpus is assembled to examine specific research questions; it is not a systematic or
representative sample, so counts and percentages should not be
interpreted as prevalence estimates for the literature as a whole.

## Corpus structure

### Set 1 --- Funding and research ecosystem

50 observations. Asks what problems are prioritized, which constructs
become research objects, and how problem framing shapes what becomes
measurable.

### Set 2 --- AI / AI-bio evaluations

42 evaluations. Asks what is measured, at what system boundary, using
what proxy/endpoint, and what capability or security inference follows.

### Set 3 --- Failure, resilience, and update trajectories

42 trajectories. Traces perturbation, propagation,
amplification/buffering, detection, attribution, correction, recovery,
feedback, and learning.

### Comparator corpus

30 sources across traditional biosafety/biosecurity, systems safety and
human factors, empirical cybersecurity, bioinformatics/data quality,
benchmark/measurement science, and successful biological workflows.

## Analytical spine

The common structure is:

**system boundary → components/relationships → flow → measurement or
perturbation → observed outcome → security inference → evidence
supporting the inference**

Key added variables include claim--demonstration distance, configuration
level, boundary sensitivity, predictive-validity evidence, physical
validation, and the feedback chain: feedback available → interpretable →
update capacity → update observed.

## Current headline results

-   30/42 (71.4%) Set 2 evaluations coded high/very-high boundary
    sensitivity.
-   37/42 (88.1%) had downstream predictive validity coded low or not
    established.
-   Feedback was available in 42/42 coded trajectories; a clear update
    was observed in 21/41 codable trajectories (51.2%).
-   Matched chains show boundary expansion has no single direction: it
    can attenuate, strengthen, or reframe a capability/security
    inference.

## Interpretation

The emerging proposition is not that larger systems are always riskier.
It is that evidence generated at one boundary may not transport cleanly
to a larger configured system whose behavior depends on relationships
that were not measured. Recurrent candidate mediators include context,
provenance, tool access, execution semantics, human expertise,
authority, physical constraints, observability, feedback
interpretability, reversibility, and update capacity.

## How to contribute

The most useful contribution at this stage is additional literature or
cases that challenge the current patterns. In particular, please
suggest: - matched benchmark → workflow → physical/deployed studies; -
null or negative results; - human--AI studies that specify expertise,
authority, observability, and intervention rather than simply "human in
the loop"; - post-safeguard or post-intervention trajectories; - real
deployment incidents, near misses, corrections, and recoveries; -
positive-control workflows in which feedback and update demonstrably
produce robust performance; - comparator literature on proxy validity,
transportability, system reliability, and field observability.

## Versioning

This snapshot reflects analysis through **v1.7 (20 September 2026)**.
Earlier analysis files are retained because they document how the
questions and coding scheme evolved. New additions should preserve
source provenance and distinguish direct source evidence, author claims,
analyst inference, and unknowns.

## Caveats

This is an exploratory research corpus. The source list includes papers,
preprints, reports, benchmarks, funder/program pages, and guidance
documents. Bibliographic metadata in the source-list document is
optimized for corpus review rather than publication; verify author
lists, venues, and publication details against the linked source before
manuscript citation.
